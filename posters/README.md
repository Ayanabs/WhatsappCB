# Editable countdown posters

Three 1080 × 1080 SVG templates: bold, celebration, and minimal. Open an SVG in a vector editor such as Inkscape, or edit it in a text editor. The text remains editable, and the shapes and colors can be changed independently.

To customize a poster:

1. Change the text in the element with `id="days"` from `07` to your desired number. Change `DAYS TO GO` to `DAY TO GO` for one day, if appropriate.
2. Replace the event name, date, time and venue in the other text elements. Shorter text works best; adjust font sizes or positions for longer names.
3. Export the edited poster as a PNG or JPEG from your editor, then upload it as the countdown poster in the app. You can also set a different exported image for each day in the countdown's daily settings.

The number in these sample graphics is static: edit and export each version you need. The app's countdown caption calculates its own remaining time, but it does not change the number printed in a poster. When editing SVG source, escape `&` as `&amp;` and `<` as `&lt;`.
